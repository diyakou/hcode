# Houshiar 2.2.6

- Houshiar is the only model provider, with API-key setup on first launch.
- Models are discovered from `https://wqai.morvism.ir/v1/models`.
- OpenAI-compatible chat and Anthropic-compatible messages use the Houshiar gateway.
- `/usage` displays account usage and balance from `/v1/usage`.
- The graphical app and terminal include Houshiar branding.

Downloads include an unsigned Windows x64 installer, Linux x64 AppImage/deb/rpm packages, and CLI archives. SHA256SUMS.txt contains artifact checksums.
