# هوشیار (Hooshcode) — دستیار برنامه‌نویسی هوش مصنوعی با API ریالی

هوشیار یک دستیار کدنویسی هوش مصنوعی برای ترمینال و دسکتاپ است که روی درگاه [هوشیار](https://houshiar-ai.ir) کار می‌کند: یک حساب، یک کلید API و پرداخت ریالی برای دسترسی به مدل‌های پیشرفتهٔ هوش مصنوعی از جمله Claude، GPT و Gemini، بدون نیاز به VPN.

این مخزن نسخهٔ متن‌باز هوشیار (Hooshcode) است و محصول رسمی تیم OpenCode نیست. برای خرید اشتراک، مشاهدهٔ تعرفه‌ها و دریافت کلید API به [وب‌سایت هوشیار](https://houshiar-ai.ir) مراجعه کنید.

## هوشیار چه می‌کند

هوشیار کد پروژهٔ شما را می‌خواند، تغییر می‌دهد و اجرا می‌کند. مدل‌های موجود را از درگاه هوشیار می‌گیرد، مصرف حساب را نشان می‌دهد و برای کارهای پیچیده چند عامل کمکی را به کار می‌گیرد. همهٔ درخواست‌ها از یک درگاه ایرانی با [پرداخت ریالی](https://houshiar-ai.ir/%D9%82%DB%8C%D9%85%D8%AA-%D9%88-%D8%AA%D8%B9%D8%B1%D9%81%D9%87) و پشتیبانی فارسی عبور می‌کنند.

- بررسی، ویرایش و بازآرایی کد در ترمینال و برنامهٔ دسکتاپ.
- دسترسی به کاتالوگ مدل‌های [درگاه هوشیار](https://houshiar-ai.ir/%D9%85%D8%B3%D8%AA%D9%86%D8%AF%D8%A7%D8%AA-api)؛ فهرست مدل‌ها سمت سرور تعیین می‌شود.
- پشتیبانی از قابلیت استدلال مدل‌ها، متناسب با امکانات هر مدل.
- نمایش مصرف و موجودی حساب با دستور `/usage`.
- نسخهٔ وب بدون نصب در [app.houshiar-ai.ir](https://app.houshiar-ai.ir).

## دریافت و نصب

ساده‌ترین راه، صفحهٔ [دانلود Hooshcode در وب‌سایت هوشیار](https://houshiar-ai.ir/%D8%AF%D8%A7%D9%86%D9%84%D9%88%D8%AF-hooshcode) است. بسته‌های جایگزین در [صفحهٔ انتشارهای همین مخزن](https://github.com/diyakou/hcode/releases) قرار می‌گیرند و محتوای هر انتشار ممکن است متفاوت باشد.

| سیستم‌عامل | فایل مناسب |
| --- | --- |
| مک با تراشهٔ اپل | `darwin-arm64.dmg` یا `darwin-arm64.zip` |
| مک با پردازندهٔ اینتل | `darwin-x64.dmg` یا `darwin-x64.zip` |
| ویندوز ۶۴ بیتی | `windows-x64.exe` |
| لینوکس ۶۴ بیتی | `.deb`، `.rpm` یا `.AppImage` |
| ابزار خط فرمان | بایگانی `cli.tar.gz` متناسب با سیستم‌عامل |

در مک، برنامه را از تصویر دیسک به پوشهٔ برنامه‌ها منتقل کنید. در ویندوز، فایل نصب را اجرا کنید. در لینوکس، بستهٔ متناسب با توزیع خود را نصب کنید یا از فایل AppImage استفاده کنید.

نسخهٔ دسکتاپ ابزار خط فرمان مورد نیاز خود را همراه دارد؛ نصب جداگانهٔ OpenCode پیش‌نیاز اجرای آن نیست. دستورهای نصب وب‌سایت OpenCode مربوط به پروژهٔ اصلی‌اند و نسخهٔ هوشیار را نصب نمی‌کنند.

## اتصال به درگاه هوشیار

در نخستین اجرا، کلید API را در پنجرهٔ اتصال وارد کنید؛ بعداً هم با دستور `/connect` قابل تغییر است. کلید در انبار اعتبارنامهٔ سرور می‌ماند و به رابط کاربری فرستاده نمی‌شود.

- نشانی پایه: `https://api.houshiar-ai.ir/v1`
- فهرست مدل‌ها: `GET /v1/models`
- مصرف حساب: `GET /v1/usage`
- [دریافت کلید API از حساب هوشیار](https://houshiar-ai.ir/auth/login)
- [مستندات کامل API](https://houshiar-ai.ir/%D9%85%D8%B3%D8%AA%D9%86%D8%AF%D8%A7%D8%AA-api)

برای استفاده از مدل‌های درگاه به کلید معتبر نیاز دارید. کلید را در مخزن، گزارش خطا یا تصویر صفحه منتشر نکنید.

## عامل‌ها

- **`build`**: عامل پیش‌فرض برای تغییر کد، مطابق مجوزهای تنظیم‌شده.
- **`plan`**: بررسی و برنامه‌ریزی؛ به‌صورت پیش‌فرض اجازهٔ ویرایش فایل ندارد و برای اجرای فرمان پوسته درخواست مجوز می‌کند.
- **`general`**: عامل کمکی برای جست‌وجو و کارهای چندمرحله‌ای، با `@general`.
- عامل‌های اصلی با کلید `Tab` جابه‌جا می‌شوند.
- گفتگوهای ذخیره‌شدهٔ حساب با همان شناسهٔ گفتگوی سرور بازیابی می‌شوند.

## چرا برنامه امضای معتبر ندارد و هشدار امنیتی نشان می‌دهد؟

**نسخه‌های فعلی هوشیار امضای دیجیتال معتبر برای انتشار عمومی ندارند؛ نسخهٔ مک نیز تأیید انتشار اپل را دریافت نکرده است.** محدودیت‌های ناشی از تحریم، دشواری احراز هویت در سرویس‌های امضا و هزینهٔ دریافت و نگهداری گواهی باعث شده‌اند فعلاً این امکان را فراهم نکنیم. این محدودیت را پنهان نمی‌کنیم و ادعا نمی‌کنیم برنامه از سوی اپل یا مایکروسافت تأیید شده است.

به همین دلیل ممکن است هنگام نصب یا اجرا با این پیام‌ها روبه‌رو شوید:

- در مک: ناشناس بودن توسعه‌دهنده، بررسی نشدن برنامه توسط اپل، یا پیامی با مضمون «برنامه آسیب دیده و قابل باز شدن نیست».
- در ویندوز: ناشناس بودن ناشر یا هشدار محافظت از رایانه توسط SmartScreen.

نبود امضای معتبر می‌تواند علت این هشدارها باشد، اما **هر خطایی را نمی‌توان به امضا نسبت داد**. پیام آسیب‌دیدگی ممکن است به خرابی دانلود یا مشکل واقعی بسته هم مربوط باشد. نبود امضا همچنین به معنی تضمین سالم یا امن بودن فایل نیست.

فایل را فقط از صفحهٔ [دانلود هوشیار](https://houshiar-ai.ir/%D8%AF%D8%A7%D9%86%D9%84%D9%88%D8%AF-hooshcode) یا انتشارهای همین مخزن بگیرید. اگر انتشار شامل `SHA256SUMS.txt` است، مقدار درهم‌سازی فایل دانلودشده را با آن مقایسه کنید تا تغییر یا خرابی نسبت به نسخهٔ منتشرشده مشخص شود. این بررسی جای امضای معتبر و تأیید هویت ناشر را نمی‌گیرد.

ما خاموش کردن سراسری قابلیت‌های امنیتی سیستم‌عامل را توصیه نمی‌کنیم. اگر به منبع فایل اعتماد ندارید یا نصب برنامهٔ بدون امضا با سیاست دستگاه شما سازگار نیست، آن را اجرا نکنید. در صورت گزارش مشکل، نسخهٔ برنامه، سیستم‌عامل، معماری پردازنده و متن کامل خطا را در [بخش مشکلات پروژه](https://github.com/diyakou/hcode/issues) بنویسید؛ کلید دسترسی و اطلاعات شخصی را ارسال نکنید.

## استقلال نصب و محدودیت‌های فعلی

هویت نصب دسکتاپ هوشیار با نام `Houshiar` و شناسهٔ `ir.houshiar.desktop` تعریف شده است؛ نسخه‌های توسعه و آزمایشی شناسهٔ جدا دارند. تنظیمات دسکتاپ از OpenCode جدا شده و طرح پیوند اختصاصی برنامه `houshiar://` است.

این جداسازی به معنی جداسازی کامل همهٔ داده‌ها نیست: ذخیره‌سازی و کشف سرویس در ابزار خط فرمان و سرور هنوز از پیاده‌سازی مشترک با OpenCode استفاده می‌کنند. داده‌ها و تنظیمات نصب قبلی به‌صورت خودکار منتقل نمی‌شوند. این تغییرات تنها پس از ساخت و انتشار بستهٔ جدید اعمال می‌شوند.

تا زمانی که پشتیبانی از به‌روزرسانی خودکار در انتشار مربوطه تأیید نشده، نسخهٔ جدید را از صفحهٔ [دانلود هوشیار](https://houshiar-ai.ir/%D8%AF%D8%A7%D9%86%D9%84%D9%88%D8%AF-hooshcode) دریافت کنید.

## سؤالات متداول

### هوشیار چیست؟

هوشیار یک دستیار کدنویسی هوش مصنوعی است که روی درگاه ایرانی [houshiar-ai.ir](https://houshiar-ai.ir) اجرا می‌شود. با یک حساب و یک کلید API به مدل‌های Claude، GPT و Gemini دسترسی می‌گیرید و مصرف را به تومان پرداخت می‌کنید.

### آیا به VPN نیاز دارم؟

نه. درگاه هوشیار از داخل ایران در دسترس است و پرداخت آن ریالی انجام می‌شود.

### کدام سیستم‌عامل‌ها پشتیبانی می‌شوند؟

ویندوز ۶۴ بیتی، مک با تراشهٔ اپل و پردازندهٔ اینتل، و لینوکس ۶۴ بیتی. نسخهٔ وب هم در [app.houshiar-ai.ir](https://app.houshiar-ai.ir) بدون نصب کار می‌کند.

### چه مدل‌هایی در دسترس است؟

فهرست مدل‌ها از درگاه خوانده می‌شود (`GET /v1/models`) و با تغییر تعرفه یا کاتالوگ به‌روز می‌شود؛ نام مدل‌ها در برنامه ثابت نشده‌اند. کاتالوگ و مشخصات را در [مستندات API هوشیار](https://houshiar-ai.ir/%D9%85%D8%B3%D8%AA%D9%86%D8%AF%D8%A7%D8%AA-api) ببینید.

### آیا API هوشیار با SDK آنتروپیک سازگار است؟

بله. مقدار `base_url` را به نشانی هوشیار تغییر دهید و از کلید هوشیار استفاده کنید؛ بقیهٔ کد تغییر نمی‌کند. نمونه‌ها در [مستندات API](https://houshiar-ai.ir/%D9%85%D8%B3%D8%AA%D9%86%D8%AF%D8%A7%D8%AA-api) آمده است.

### هزینه چقدر است؟

تعرفه‌ها و بسته‌های اعتباری در صفحهٔ [قیمت و تعرفهٔ هوشیار](https://houshiar-ai.ir/%D9%82%DB%8C%D9%85%D8%AA-%D9%88-%D8%AA%D8%B9%D8%B1%D9%81%D9%87) به‌روز نگه داشته می‌شوند.

## اجرای پروژه از کد منبع

برای توسعه به گیت و نسخهٔ Bun مشخص‌شده در فیلد `packageManager` فایل `package.json` نیاز دارید.

</div>

```bash
git clone https://github.com/diyakou/hcode.git
cd hcode
bun install
```

<div dir="rtl" align="right">

اجرای محیط ترمینال از کد منبع:

</div>

```bash
bun run dev
```

<div dir="rtl" align="right">

اجرای دسکتاپ در حالت توسعه:

</div>

```bash
bun run dev:desktop
```

<div dir="rtl" align="right">

بررسی کامل قواعد کدنویسی و نوع‌ها، از ریشهٔ مخزن:

</div>

```bash
bun run check
```

<div dir="rtl" align="right">

آزمون‌ها را از پوشهٔ بستهٔ مربوطه اجرا کنید؛ اجرای آزمون از ریشهٔ مخزن پشتیبانی نمی‌شود. جزئیات در `AGENTS.md` هر بخش آمده است.
